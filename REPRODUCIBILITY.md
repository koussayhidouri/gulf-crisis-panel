# Reproducibility audit

## Run performed

The current R script was run with R 4.6.1 and the project dependencies. It completed and regenerated both regression tables and all four plots. The analysis sample has 492 rows after within-country first differencing (12 countries x 41 months). Subgroup models use freshly indexed panel subsets to avoid invalid `pdata.frame` warnings.

The run produced four R startup locale warnings because this Windows environment does not provide the configured `C.UTF-8` locale. No model or plotting warnings remained.

From the project root, use:

```r
.libPaths(c(".R-library", .libPaths()))
source("scripts/analyze_panel.R")
```

`.R-library/` is a local dependency cache and is excluded from version control. Install dependencies with `install.packages()` as needed instead of committing this directory.

## Changes in the current script

- Dates are parsed and observations sorted by country and month before differencing.
- CPI, IPI, and NEER log differences are constructed within each country.
- Main CPI/IPI regressions, heterogeneity regressions, and the importer interaction model use the differenced outcomes and differenced NEER described in the report.
- The supplied common `oil_pct_change` series is retained; recomputing a lag after arranging country-month rows would create invalid cross-country transitions.

## Unresolved differences from the supplied report

The regenerated results do not reproduce the PDF's regression tables. The PDF reports pooled OLS oil-shock coefficients of -0.098 for CPI and +0.081 for IPI. The current run produces approximately +0.00034 for CPI and -0.00018 for IPI. The signs and magnitudes differ, so these are not rounding differences.

The current code also includes `post_crisis` in the fixed-effects model, while the PDF's table omits it. The current diagnostic p-values are close to, but not identical to, those reported in the PDF. These discrepancies may reflect differences in the data, variable scaling, transformations, or model specifications; the available files do not establish which version is authoritative.

Until the team verifies the source series, variable units, transformations, forecast procedure, and final model specification, the PDF's numerical interpretations should not be presented as results regenerated by this repository. Current output tables are stored in `results/tables/`, and generated figures are stored in `results/figures/`.
