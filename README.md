# Gulf Crisis Panel Analysis

Advanced econometrics team project examining monthly oil price changes, CPI inflation, and industrial production across 12 countries from January 2023 through June 2026.

## Project status

The supplied report, dataset, and analysis script do not currently reproduce one another. Treat the estimates as unresolved until the source series, units, and specification are reconciled.

The dataset contains 504 country-month rows. April-June 2026 values are marked as forecasts in `is_forecast`; they are part of the original analysis vintage, not observed data. The report calls the panel unbalanced in its abstract and balanced elsewhere.

## Project layout

- `data/panel_data.csv` - supplied panel dataset.
- `report/gulf-crisis-panel-report.pdf` - original team report, retained as received.
- `scripts/analyze_panel.R` - analysis script, updated to construct within-country log differences and use them in the main and subgroup models.
- `results/tables/` and `results/figures/` - outputs generated by the current script. These are not the tables and figures embedded in the original report.

## Reproduce the current script outputs

Requires R 4.6.1 or later and the packages `tidyverse`, `plm`, `lmtest`, `stargazer`, `ggplot2`, `car`, and `forecast`.

From the project root, install any missing packages in R:

```r
install.packages(c("tidyverse", "plm", "lmtest", "stargazer", "ggplot2", "car", "forecast"))
```

Then run:

```r
source("scripts/analyze_panel.R")
```

Run the script with the project root as the working directory. It writes tables to `results/tables/` and figures to `results/figures/`. The supplied `oil_pct_change` series is retained; it should not be recalculated using a lag across country rows.

## Reproducibility notes

The current script was run with R 4.6.1. It regenerated both regression tables and all four figures from the supplied data. First-differencing leaves 492 observations (12 countries x 41 months). Subgroup models use freshly indexed panel subsets after filtering.

The PDF reports pooled OLS oil-shock coefficients of -0.098 for CPI and +0.081 for IPI. The current run produces approximately +0.00034 for CPI and -0.00018 for IPI. These differences in sign and magnitude are not rounding differences. The code also includes `post_crisis` in the fixed-effects model, while the report's table omits it. The available files do not establish whether the differences come from data, units, transformations, or model specification. The generated tables in `results/tables/` are outputs of the current script, not reproductions of the PDF tables.

The script run completed with no model or plotting warnings. R emitted four startup locale warnings because this Windows environment does not provide the configured `C.UTF-8` locale.

The `.R-library/` directory is a local dependency cache and is excluded from version control. To use an existing local cache when running the script:

```r
.libPaths(c(".R-library", .libPaths()))
source("scripts/analyze_panel.R")
```

Install the listed packages with `install.packages()` as needed.

## Scope

The models estimate associations in a short panel with forecasted observations included. They do not establish causal effects. Data provenance, variable units, forecast procedures, and the report-versus-code discrepancy need to be resolved before treating the estimates as final findings.
