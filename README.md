# Gulf Crisis Panel Analysis

Advanced econometrics team project examining monthly oil price changes, CPI inflation, and industrial production across 12 countries from January 2023 through June 2026.

## Project status

This is an academic team project. The supplied report, dataset, and original R script do not currently reproduce one another. A reconciliation run is documented in [REPRODUCIBILITY.md](REPRODUCIBILITY.md). The project should not be cited or presented as a verified replication until that discrepancy is resolved.

The dataset contains 504 country-month rows. April–June 2026 values are marked as forecasts in `is_forecast`; they are part of the original analysis vintage, not observed data. The report itself also contains inconsistencies, including calling the panel unbalanced in its abstract while describing it as balanced elsewhere.

## Files

- `Gulf_Crisis_Panel_Analysis_Report .pdf` — original team report, retained as received.
- `panel_data_gulf_crisis_2026.csv` — supplied panel dataset.
- `panel_analysis_gulf_crisis_2026.R` — analysis script, updated to construct within-country log differences and use them in the main and subgroup models.
- `table_*_models.txt`, `plot_*.png` — outputs generated by running the current script; they are not the tables and figures embedded in the original PDF.
- `REPRODUCIBILITY.md` — commands, audit findings, and open reconciliation points.

## Reproduce the current script outputs

Requires R 4.6.1 or later and the packages `tidyverse`, `plm`, `lmtest`, `stargazer`, `ggplot2`, `car`, and `forecast`.

From this folder, install any missing packages in R with:

```r
install.packages(c("tidyverse", "plm", "lmtest", "stargazer", "ggplot2", "car", "forecast"))
```

Then run:

```r
source("panel_analysis_gulf_crisis_2026.R")
```

The script writes tables and figures into the working directory. The supplied `oil_pct_change` series is retained as provided; it should not be recalculated using a lag across country rows.

## Scope and interpretation

The models estimate associations in a short panel, with forecasted observations included. They do not establish causal effects. The forecast vintage, data provenance, variable units, and report-versus-code discrepancies need to be resolved before treating the estimates as final findings.
